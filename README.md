One image that sums up the world news of Tuesday 17 November 2026, drawn as a one-page newspaper poster: Ukraine's strike on the Crimea Bridge, a tanker attacked in the Strait of Hormuz, Nvidia's first earnings report after Jensen Huang's resignation, the global stock slide that put the Nasdaq in correction, the Quad leaders' meeting in Manila, and Delhi's smog crisis as Cyclone Akvan neared the Indian coast — plus a ticker of the day's smaller stories. The poster is drawn in `poster.html` (HTML/CSS with inline SVG) and rendered to `entry.png` by `render.mjs`; the entry program `main.ts` verifies the PNG and copies it to `/output/entry.png`, byte for byte, every run.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
